# Руководство по JVM и Garbage Collection

Этот раздел описывает архитектуру Java HotSpot VM и методы настройки сборщиков мусора для достижения оптимальной производительности.

## Архитектура JVM

- **Class Loader** – загрузка классов по запросу.
- **Runtime Data Areas**:
  - **Heap** – область для объектов (основная зона GC).
  - **Stack** – фреймы методов, локальные переменные.
  - **Metaspace** – метаданные классов (заменяет PermGen).
  - **PC Registers** – счётчики инструкций.
- **Execution Engine** – интерпретатор и JIT-компилятор (C1, C2).

## Сборщики мусора (Garbage Collectors)

Выбор GC зависит от требований к пропускной способности и задержкам.

| Сборщик          | Особенности                                             | Параметр включения                 |
|------------------|---------------------------------------------------------|------------------------------------|
| Serial GC        | Однопоточный, для малых куч и клиентских приложений      | `-XX:+UseSerialGC`                |
| Parallel GC      | Многопоточный, высокая пропускная способность            | `-XX:+UseParallelGC`              |
| G1 GC            | Баланс пропускной способности и задержек (серверный)     | `-XX:+UseG1GC` (по умолчанию)     |
| ZGC              | Сверхнизкие задержки (масштабируемый)                    | `-XX:+UseZGC`                     |
| Shenandoah GC    | Низкие задержки, альтернатива ZGC                        | `-XX:+UseShenandoahGC`            |

## Настройка размера кучи

- `-Xms<size>` – начальный размер кучи.
- `-Xmx<size>` – максимальный размер кучи (рекомендуется 50-80% от физической памяти).
- `-XX:MaxMetaspaceSize=<size>` – лимит Metaspace.

## Ключевые параметры настройки GC

- `-XX:MaxGCPauseMillis=<ms>` – целевая пауза (актуально для G1, ZGC).
- `-XX:G1HeapRegionSize=<size>` – размер региона в G1.
- `-XX:ConcGCThreads=<n>` – количество потоков для параллельной обработки.
- `-XX:ParallelGCThreads=<n>` – количество потоков для параллельных фаз.

## Примеры настройки

**Для веб-приложения с высокой нагрузкой и чувствительностью к задержкам:**
```bash
java -Xms4g -Xmx4g -XX:+UseG1GC -XX:MaxGCPauseMillis=100 -jar myapp.jar
