# Библиотека знаний Java SE 25

Этот набор документов предназначен для ИИ-агентов и разработчиков, работающих с платформой Java SE 25 (LTS). Документация охватывает все ключевые аспекты: язык, библиотеки, JVM, безопасность, инструменты и устранение неисправностей. Каждый раздел содержит как официальные сведения, так и практические примеры кода.

## Оглавление

1. [Обзор Java SE 25](./01_overview_java25.md) – нововведения (JEP), архитектура, roadmap.
2. [Руководство по миграции](./02_migration_guide.md) – как перейти на JDK 25, проверка совместимости.
3. [Руководство по установке](./03_installation_guide.md) – установка JDK/JRE на разные ОС.
4. [Руководство по Core Libraries](./04_core_libraries_guide.md) – работа с коллекциями, стримами, временем, Scoped Values, Structured Concurrency.
5. [Руководство по JVM и Garbage Collection](./05_jvm_gc_guide.md) – архитектура HotSpot, настройка GC, мониторинг.
6. [Руководство по безопасности](./06_security_guide.md) – криптография, KDF, PEM, SSL/TLS, политики.
7. [Руководство по инструментам](./07_tools_guide.md) – JShell, Javadoc, jpackage, компиляция, упаковка.
8. [Руководство по устранению неисправностей](./08_troubleshooting_guide.md) – анализ дампов, логов, Flight Recorder.

## Как использовать

- ИИ-агенты могут обращаться к этим файлам для получения точной информации о возможностях Java 25.
- Разработчики найдут примеры кода для быстрого внедрения новых функций.
- Все примеры основаны на официальной документации и проверены в реальных проектах.

**Примечание:** Для работы с preview-функциями (JEP 470, 507) используйте флаг `--enable-preview` при компиляции и запуске.
