# Обзор Java Platform, Standard Edition 25 (Java SE 25)

Java SE 25 — это пятый долгосрочный (LTS) релиз в рамках шестимесячного цикла обновлений. Релиз состоялся 16 сентября 2025 года и включает в себя **18 JEP (JDK Enhancement Proposals)**, которые приносят значительные улучшения в язык, производительность, безопасность и библиотеки.

## Ключевые нововведения (JEP)

### Языковые возможности
- **Гибкие тела конструкторов (Flexible Constructor Bodies) (JEP 513)** – упрощает написание конструкторов, снимая ограничения на вызовы `super()` и `this()`.
- **Компактные исходные файлы и метод `main` экземпляра (JEP 512)** – позволяет писать простые программы без явных классов и статического `main`.
- **Объявления импорта модулей (JEP 511)** – импорт всех пакетов модуля одной строкой.
- **Примитивные типы в шаблонах, `instanceof` и `switch` (третье превью) (JEP 507)** – сопоставление с образцом для примитивов.

### Производительность и JVM
- **Уменьшенные заголовки объектов (Compact Object Headers) (JEP 519)** – сокращение размера заголовка объекта до 64 бит, уменьшение потребления памяти.
- **Упреждающее профилирование методов** – ускорение "прогрева" JVM за счёт данных профилирования с прошлых запусков.

### Безопасность
- **PEM-кодировки криптографических объектов (Preview) (JEP 470)** – упрощение работы с сертификатами и ключами в PEM-формате.
- **API функций вывода ключей (Key Derivation Function API) (JEP 510)** – подготовка к пост-квантовой криптографии.

### Библиотеки и API
- **Scoped Values (JEP 506)** – альтернатива `ThreadLocal` для передачи неизменяемых данных в виртуальных потоках.
- **Векторный API (десятый инкубатор)** – векторные вычисления для AI/ML.
- **Структурированный параллелизм** – управление многопоточностью в рамках блока.
